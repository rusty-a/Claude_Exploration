# Claude_Exploration

Projects built with Claude.

- [fan-spot-finder](fan-spot-finder/): a room air-flow sketch that finds the best spot for a fan.
  **[Open the app](https://rusty-a.github.io/Claude_Exploration/fan-spot-finder/app/)**
- [surrogate-benchmark](surrogate-benchmark/): a U-Net and an FNO surrogate for 2D flow past a cylinder, benchmarked against
  coarse versions of the solver that made the data (fair speed-up, break-even, failure outside the training range).
